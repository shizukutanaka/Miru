4つの独自軸

他のリモートデスクトップソフトが対応していない領域を、設計の初日から組み込みました。

1

AI Agent First Class

Claude / GPT 等の AI エージェントが Miru ホストを安全に制御。 11個の細粒度 capability、時限式トークン、改ざん検知付き audit log。 Anthropic Computer Use 等の標準基盤候補。

2

Verifiable E2E

各セッションのメタデータを暗号学的にコミット。両端の Ed25519 共同署名 + Sigstore Rekor 対応。「E2E」を主張ではなく数学的に証明できます。

3

Device Constellation

全デバイス (デスクトップ / ノート / スマホ / サーバー) を Ed25519 署名グラフで 束ねて可視化。1:1 接続ではなく N:N の fabric。クロス OS のハンドオフ対応。

4

Time Travel

全セッションを deterministic に記録。Premiere 風スクラバー + 倍速 + ブックマーク。監査・教育・デバッグ用の4D UI。

なぜ信頼できるか

主張ではなく、数学とコードで証明できるものだけを書いています。

暗号

X25519 + ChaCha20-Poly1305 + Ed25519. PFS と HKDF-SHA256 で 各セッション独立鍵。

パスワード

Argon2id (64MB / 3 iter / 4-way)。RustDesk の CVE-2026-30785 を 回避する設計。

TLS

full validation 強制。RustDesk CVE-2026-30794 のような 検証無効フォールバックを構造的に提供しません。

ファイル転送

O_NOFOLLOW + path 正規化 + 許可ルート検証。 CVE-2026-2490 のシンボリックリンク漏洩を防止。

テレメトリ

一切なし。クラッシュレポートも opt-in、差分プライバシー適用。

再現可能ビルド

同じコミットからは bit-identical なバイナリ。 検証スクリプト同梱、GitHub Releases に SHA256SUMS。

外部監査

v1.0 で年1回 Trail of Bits 等による外部監査を予定。 結果は全文公開。

Post-quantum

v2.0 で X25519 + Kyber768 ハイブリッド。 量子コンピュータ前提の脅威モデル対応。
