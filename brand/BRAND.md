# Miru ブランドガイドライン

## 名称

- 正式名: **Miru**
- 由来: 日本語の「見る」(to see)
- 表記: 常に "Miru" (タイトルケース)。"miru" や "MIRU" は不可
- 発音: ミ・ル

## ロゴ

- `brand/logo.svg`: アイコン単独 (1:1)
- `brand/wordmark.svg`: アイコン + 文字 (4.5:1)
- 最小表示サイズ: 16px (アイコン), 80px (ワードマーク)
- セーフエリア: ロゴ高さの 1/4 を四方に確保

### 使ってはいけないこと

- ロゴの色を変更しない (グラデーションは固定)
- 立体化・影・グロー追加禁止
- 他のロゴと重ねない
- 回転禁止

## モーション

- イージング: `cubic-bezier(0.2, 0, 0.13, 1.5)` (やや跳ねる)
- 標準時間: 120ms (UI 反応), 200ms (展開), 400ms (画面遷移)
- `prefers-reduced-motion: reduce` を必ず尊重

## トーン (コピーライティング)

- 基本: 平易・能動形・短く
- 日本語第一、英語は二次
- 「お客様」ではなく「あなた」(でも適度な敬語は維持)
- 具体的・検証可能な主張のみ書く
  - ✓ "Argon2id (64MB / 3 iter / 4-way)"
  - ✗ "業界最高水準のセキュリティ"
- 絵文字は基本使わない (UI / docs / マーケティング全て)
- 顔文字は使わない (`(^_^)` 等)
- 専門用語は最初に出るとき必ず括弧で説明

## ロゴ意図 (シンボリック解説)

3つの同心角丸正方形:
- 外側: ピア (相手の端末)
- 中: リレー層 (信頼境界)
- 内: 自端末 (色付き = active)

中心の黒い点: **見る**瞬間。Miru = 見る。

E2E 暗号化を視覚化: 外側のリングは半透明 (信頼度低)、内側に向かって不透明度が増す。
